Birthday Surprise Website — revised

Files:
- index.html
- birthday-background-song.mp3

Keep both files in the same folder. The MP3 is the supplied birthday background track and loops continuously at a gentle volume. Browser autoplay rules may require the visitor's first tap before the music starts. The speaker button toggles mute/unmute.

Balloon screen: returning to the balloon screen resets all balloons and their hidden-word state so they can be burst again.

For local testing, extract the ZIP and open index.html in a modern browser. Microphone access generally requires HTTPS or localhost; the candle can always be tapped instead.

For GitHub Pages, upload BOTH index.html and birthday-background-song.mp3 to the repository root, then enable Settings > Pages > Deploy from a branch > main > /(root).
